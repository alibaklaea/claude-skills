## 🚀 Kurulum

### 1. Repository'yi Klone Et

```bash
git clone https://github.com/alibaklaea/claude-skills.git
cd claude-skills
```

### 2. Git Ayarları Yap (İlk Kez)

```bash
git config --global user.name "Senin Adın"
git config --global user.email "senin-email@example.com"
```

### 3. Claude Code'a Skills'i Ekle

`.claude/skills/` klasörünün içindeki her skill zaten hazır!

Şu adımları izle:
- Claude Code açık olsun
- Settings → Skills bölümüne git
- `.claude/skills/` klasöründeki skill'leri seç
- Yükle
